[P2 documentation] Hosting guarantee overstated — fixed

The guide said reporting ran only on Vercel production deployments. The implementation checks VERCEL_ENV, which any host can set. This could lead an operator to enable reporting unintentionally in a local or non-Vercel process.

The guide now names the exact environment-variable gate, distinguishes browser build-time configuration from server runtime configuration, and explains that setting VERCEL_ENV=production enables reporting on any host. The source-map section uses the same precise condition. Runtime behavior was preserved.

Confidence: high. This is proved by the initialization files, build configuration and existing deployment tests. Original Cubic finding.
